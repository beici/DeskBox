# DeskBox 1.5.9 — 本分支增强版

发布日期：2026-11-10。上游对照：Tianyu199509/DeskBox 的 v1.5.9 标签。版本号保持 1.5.9，本页描述 beici/DeskBox 的完整本地增强版本。

## 新增和优化

- 番茄钟格子：专注与休息轮次、暂停/继续/重置/跳过、提醒、主题与高对比支持。
- 截图工具：区域/窗口/工作区/全屏捕获、图形和文字标注、马赛克/模糊、取色、复制/保存、撤销/重做、贴图。
- 胶囊渲染：修复原生激活和收起后的相邻阴影暗化、置顶层迁移错误及背景闪亮；补齐同类顺序恢复的请求生命周期。
- 性能：改进自适应动画节奏、增量文件同步、视口渲染扩展、背景/缩略图缓存和隐藏组件的刷新策略。
- 可靠性：改进设置与备份一致性、取消和恢复流程、拖放、快捷方式、压缩文件、安装升级与卸载路径验证。
- 体验：调整天气图标、番茄钟外观、截图选区及快捷键交互，新增资源覆盖 13 种语言。
- 发布复核：修复缩略图解码后源文件仍被占用的问题，统一截图文字的原生接口边界，补齐音乐和番茄钟测试的数据隔离与保存等待。
- 构建：Native AOT 编译器和内置 .NET 运行时锁定到 10.0.14；Release 构建对 C#、Rust 源码路径和符号路径做映射，避免二进制携带构建账户目录。

上游已有能力的完整介绍见 [README](../../README.zh-CN.md)。胶囊问题的机制和验收方法见[排障手册](../quality/capsule-title-shadow-20261109.md)。

## 安装

提供 `DeskBox_Setup_1.5.9_x64.exe` 和对应 `.sha256` 校验文件，适用于 Intel / AMD 64 位 Windows。安装包内置所需运行时，无需安装时联网下载。本次没有发布 ARM64 或 32 位 x86 安装包。安装包未签名。

若已安装上游同版本 1.5.9，版本检查不会将同版本视为更新，请手动运行本分支安装包。安装前可通过应用的数据备份功能保存现有配置。

应用内更新器继续指向上游，方便关注上游动态；本分支的安装包从 beici/DeskBox Releases 手动下载。

## 验证

发布门禁包括 x64 全量测试、13 种语言键及占位符检查、静态规则检查、Native AOT 审计、离线安装载荷检查和源码/二进制隐私扫描。最终测试计数及安装包校验值随 GitHub Release 公布。

可在 Windows 开发环境重跑：

```powershell
dotnet restore .\DeskBox.sln --locked-mode -p:Platform=x64 -p:RuntimeIdentifier=win-x64
dotnet test .\tests\DeskBox.Tests\DeskBox.Tests.csproj --configuration Release --no-restore -p:Platform=x64 -p:RuntimeIdentifier=win-x64 -p:WindowsAppSdkBootstrapInitialize=false
python -m unittest discover -s scripts/quality -p test_static_gate.py
python scripts/quality/static_gate.py
.\scripts\publish-aot-audit.ps1 -Platform x64
.\scripts\publish-aot-retail.ps1 -Platform x64
```

测试通过数必须等于总数；审计和零售发布应基于同一份冻结源码。静态字符串检查仅作辅助，不能替代真实测试的切片断言。

胶囊实机验证已覆盖 Windows 11、125% DPI、Dynamic 和 Acrylic；一次有效激活序列的 41/41 可见采样正常。冷启动后的连续激活矩阵未完整完成，Windows 10、其他层级模式及 GPU/DPI 组合需继续实机复查。详见排障手册中的证据与限制。

源码及安装包不包含正式配置、个人文件、原始截图、采样日志或本机凭据。

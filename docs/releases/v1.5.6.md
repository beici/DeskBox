# DeskBox 1.5.6

DeskBox 1.5.6 is a quality and reliability release. Eight full-tree defect-review rounds ran against the 1.5.5 baseline, and every finding was fixed, verification-gated, and re-reviewed by an independent pass before merge. There are no new features in this release on purpose: 130+ findings (all severity P3 or lower at disclosure, none blocking production) were closed across data safety, concurrency, persistence, installer behavior, and dead-code retirement. The test suite grew from 4,059 to 4,291 cases and the localized string set is parity-checked at 2,667 keys across all twelve languages.

Release date: 2026-09-27 (packaged from the `wip/fix-bug` quality campaign, source baseline `7387efeb` plus the release version bump).

## Data safety

- Search result actions ("save to quick capture", "append to todo") now go through the owning service caches. Previously they wrote the JSON stores directly, so the next regular save could silently drop entries written this way.
- Quick-capture and todo stores serialize all writes per store path. Two writers racing (background reminder sweep vs. widget edit) can no longer interleave and lose one side's changes.
- Copy rollback in managed folder transfers no longer deletes a same-named file that some other process placed at the destination while the copy was running; rollback only removes objects this operation created.
- Read-only files no longer break cross-volume directory moves with a "split tree" failure: the source cleanup clears the read-only flag on files it owns before deleting.
- Cloud backup and restore normalize malformed archives and server responses into explicit, localized errors instead of leaking `InvalidOperationException`/`UriFormatException` text.
- A settings file written by a newer DeskBox build is no longer silently overwritten (unknown fields dropped) — the store refuses the write and keeps your data.

## Reliability

- The group-detach preview no longer dead-locks the UI thread when a preview window is dismissed while a background poller holds the same lock.
- Folder watchers no longer stall the UI for seconds per reconnect tick against offline network paths; path resolution and availability probes run off the UI thread with generation-guarded settlement.
- The global hotkey and search-hotkey recorders ignore reserved hook mask keys; hook health is watchdogged.
- Merging widget groups now cancels any in-flight surface member switch first, closing the one topology entry that raced the switch settlement window.
- The onboarding window retires its legacy five-step flow (seven permanently hidden panels, ~5,500 lines) in favor of the task flow; the brand mark is actually visible during onboarding now, and the intro→content handoff protocol operates on visible elements only.
- The updater reports a failed post-install restart instead of leaving the machine with no running DeskBox and no signal.

## Installer

- The dependency check now also detects user-level .NET 10 installs (`%LOCALAPPDATA%\Microsoft\dotnet`), so users who installed .NET without elevation no longer get a redundant 55 MB download and an unexpected UAC prompt.

## Internals

- Eight review rounds closed 130+ findings: cross-thread collection access, RCW/handle disposal gaps, `async void` silent-failure entry points, culture-sensitive parsing, hot-path allocations, and ~5,500 lines of dead code (a never-wired Shell IDropTarget delegation subsystem among them) retired.
- Contract ratchets were recalibrated to the current tree; the WMC1510 AOT audit pin (742) and ABI frozen contract (ABI 2, capability mask 511, ten exports) re-verified end to end on the release packaging run.

# 格子与截图体验优化（2026-11-05）

本轮围绕 Fluent 天气图标、格子展开收起与滚动、截图交互进行修改；不继续此前的全量循环审查。

## 实现

- 天气：重绘 Fluent 的雨、雾 SVG。统一云层明暗，缩小并倾斜雨滴，雾带改为错落分段，避免原来突兀的圆块和逐级缩短的条纹。维持 32×32 画布，不增加运行时依赖。
- 展开收起：移除全局记忆的降帧档位和逐帧取模跳帧。每次动画使用自己的时间截止点和实际提交耗时调节频率；用户帧率上限也用时间间隔表达，支持 165 Hz / 60 fps 等不能整除的组合。保留首帧同步、受限时间步进和最终状态清理。
- 闪烁：动画期间延后背景刷新；完成时只刷新动画经过区域内的窗口，并跳过仍在动画中的窗口。桌面整体显示状态变化仍保留全局刷新入口。
- 滚动：由 WinUI 管理滚动条显示和淡出，不再在每次鼠标移动时切换 Hidden/Auto、重启定时器。视口补充任务合并到低优先级调度，按一页的大小补充 16–64 项，避免滚动回调中同步追加 200 项。
- 截图：直接上传已捕获的 BGRA 像素，准备好底图后才显示覆盖层；初始化失败会关闭窗口并释放单实例门闩。选区内部可拖动，误点外部保留选区，双击确认当前选区；先提交手势再释放指针捕获。
- 截图完成操作：Enter 复制、Ctrl+S 保存；保留 Ctrl+C、F3、Ctrl+Z/Y。文字输入时不抢占复制和撤销。提交待编辑文字后再导出，导出期间锁定选区和标注；剪贴板暂忙时有限重试。
- 截图工具：添加工具名称、快捷键提示和辅助功能名称，补全 13 种语言。选区底图按图像与矩形缓存，避免切换工具时重复裁剪。

## 手动验证

1. 从 E:\DeskBox-debug\DeskBox.exe 启动。天气图标风格选择 Fluent，观察雨、雾在当前背景上的轮廓。
2. 连续展开/收起多个格子；在文件较多的格子内拖动滚动条，并在滑块上停留超过三秒，检查滑块是否保持可操作、内容是否连续补充，以及相邻格子是否闪烁。
3. 启动截图，拖出选区；在内部拖动、拖动边缘调整大小、在外部单击。预期单击不会替换选区。
4. 添加文字后用按钮复制；另一次使用 Enter 复制、Ctrl+S 保存并取消保存。预期文字包含在结果中，取消后仍可继续调整。
5. 编辑文字时使用 Ctrl+C / Ctrl+Z，预期作用于文字输入，不触发截图导出或标注撤销。

1. **DEF-086（settings.json 只读防护）**：数据丢失类、影响所有跨版本用户。修法方向：把 `WidgetLayoutStore.CanWrite` 的「LoadedSchemaVersion > Current → 拒绝覆写 + 保存报失败」同型守卫移植到 settings.json 写路径（仿照 `SaveToFileOnlyAsync` 已有的 layout 段落即可，基础设施齐全）。

3. **DEF-087（钩子同步握手）**：低频但最长 ~2.15s UI 冻结。修法方向：握手改异步（`await` + 超时）或移出 UI 线程；六个调用点统一封装。
4. **低成本速赢批（P3，合计约半天）**：DEF-095（`ReferenceEquals` 改值相等，一行）、DEF-088（watchdog 移出 `using var`）、DEF-091（改 6 行注释）、DEF-093（手册三处同步）、DEF-099/100（死事件删除或接线）、DEF-092（死代码删除）、DEF-098（配色基线走主题）。

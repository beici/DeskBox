# 随记（QuickCapture）全功能人工回归清单 —— DEF-027 死宿主删除前基线

> 用途：`Views/QuickCaptureWidgetWindow*` 13 文件（7,796 行）删除前，确认随记功能的**现役实现路径**（`QuickCaptureSurfaceContent` + `ContentWidgetWindow`）不受影响。请在 Windows 侧构建后逐项勾验。
> 背景：死宿主自 B2 配色移植（RECT-3）与 DEF-009 修复起已零实例化，删除不改变任何运行时行为；本清单用于给删除批次一个可对照的「删除前基线」。

## A. 记录与显示
- [ ] A1 复制文本 → 新记录出现在列表顶部（PlainText）
- [ ] A2 复制 URL → 识别为链接记录（可点击）
- [ ] A3 截图/复制图像 → 图像记录入库，缩略图显示
- [ ] A4 复制文件 → 附件记录入库
- [ ] A5 记录格式正确渲染：Markdown 记录渲染标题/列表/内嵌图；纯文本按原文显示
- [ ] A6 最近列表上限（默认 30 条）滚动淘汰正常

## B. 详情编辑
- [ ] B1 打开任意记录详情 → 只读视图内容与列表一致
- [ ] B2 进入编辑（按钮/F2/双击）→ **格式保持记录原格式**（DEF-011：Markdown 记录仍显示 Markdown 工具栏）
- [ ] B3 编辑保存（含 600ms 自动保存）→ 内容更新、格式不漂移
- [ ] B4 新建记录（详情面板）→ 使用应用默认格式
- [ ] B5 修改标题/外观预设 → 保存后生效

## C. 删除与撤销
- [ ] C1 删除单条文本记录 → toast 提示 + 点撤销 → 记录回原位
- [ ] C2 删除单条**图像**记录 → 4.2s 内点撤销 → 记录恢复且**图片完好**（DEF-012 核心场景）
- [ ] C3 删除图像记录后**不**撤销，等 10 秒后再触发一次新图像入库 → 图片文件被正常回收（磁盘可验证）
- [ ] C4 多选删除 → 批量撤销全部恢复
- [ ] C5 清空最近列表 → 图像缓存同步清理

## D. 剪贴板记录与自写忽略
- [ ] D1 开启记录后复制任意文本 → 正常入库（无自我回录垃圾，DEF-009 修复仍有效）
- [ ] D2 在随记里复制一条记录 → 2 秒内不产生自回录
- [ ] D3 复制与 DeskBox 刚写入相同文本 → 过窗后恢复回录

## E. 配色（B2 功能）
- [ ] E1 格子菜单/设置 → 记录配色：设置自定义文字色 → 记录文字变色
- [ ] E2 自定义背景色 → 卡片背景变色（优先于材质预设）
- [ ] E3 保存对比度不足的组合 → 被校验拦截（保存时）
- [ ] E4 自定义文字色 × 跟随主题背景 → 切换系统主题 → 若跌破阈值背景自动回退跟随主题（DEF-013）
- [ ] E5 一键恢复默认 → 两个通道回到跟随主题

## F. 拖拽与附件
- [ ] F1 从列表拖拽记录到桌面/资源管理器（图像记录出图、文本记录出文本）→ 正常（DEF-023 后延迟供货路径）
- [ ] F2 拖拽文件进随记 → 入库为附件
- [ ] F3 记录内拖动排序（非最近列表）→ 持久化

## G. 宿主与窗口
- [ ] G1 托盘/热键唤起随记格子 → 正常激活（DEF-015 日志锚点如触发为正常诊断）
- [ ] G2 胶囊态 ↔ 展开态切换 → 无布局残留
- [ ] G3 显示桌面后格子恢复正常（DEF-001 自愈链路 + DEF-017 hook 健康时）

**通过标准**：以上全部勾验通过（或记录异常明细）后，DEF-027 死宿主删除方可合入；删除后建议再抽测 A1/B2/C2/E1 三项确认无行为漂移。
